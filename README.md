# Foreign Direct Investment and Domestic Economic Linkages in Ireland

### Overview

This repository contains Python code developed for an independent undergraduate research project examining the relationship between multinational activity, domestic economic linkages, and indigenous enterprise development in Ireland.

Using data from the Annual Business Survey of Economic Impact (ABSEI), covering 2000–2024, the project investigates whether the expansion of foreign-owned enterprises has been accompanied by stronger domestic sourcing relationships and improvements in indigenous productive capabilities.

### Research Questions

1. To what extent has the expansion of multinational activity in Ireland been accompanied by stronger domestic economic linkages and indigenous enterprise development?
2. How might government institutions and industrial policies facilitate the development of domestic productive capabilities?

### Data

The analysis draws on ABSEI data, including:

- Employment, sales, exports, and value added
- Irish-sourced materials and services
- Enterprise ownership and sector classifications
- Value added per employee

### Methods and Tools

**Language:** Python

**Libraries:** pandas, NumPy, Matplotlib, openpyxl (as applicable)

The code supports data cleaning, variable construction, panel assembly, descriptive analysis, and visualization.

### Research Status

This is an ongoing research project. The repository documents the empirical data-processing workflow and preliminary descriptive analysis. Results should not be interpreted as establishing causal relationships.
